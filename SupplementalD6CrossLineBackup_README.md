# Backup: complete-D6 cross-line terms

This backup material is not intended for the main manuscript unless a referee
explicitly asks for the complete open-field cross-line dimension-six terms.

The machine-readable Borel integrands are:

- `d6_chunks/AA_c2b1_fast_borel_integrand.wl`
- `d6_chunks/AA_c1b2_fast_borel_integrand.wl`
- `d6_chunks/AB_c2b1_fast_borel_integrand.wl`
- `d6_chunks/AB_c1b2_fast_borel_integrand.wl`
- `d6_chunks/BB_c2b1_fast_borel_integrand.wl`
- `d6_chunks/BB_c1b2_fast_borel_integrand.wl`

Topology labels:

- `c2b1`: \(S_c^{(GG,\mathrm{open})}S_b^{(G,\mathrm{open})}\)
- `c1b2`: \(S_c^{(G,\mathrm{open})}S_b^{(GG,\mathrm{open})}\)

At the central point \(M^2=8.0~\mathrm{GeV}^2\), \(s_0=54.0~\mathrm{GeV}^2\),
the complete cross-line contribution shifts the mixing angle by
\(-2.84\times10^{-4}\) degrees, so it is numerically negligible for the quoted
result.
